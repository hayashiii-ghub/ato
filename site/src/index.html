初回起動について

このアプリはAppleの公証を受けていません。開発元や安全性を確認できないという警告が出た場合は、このプロジェクトの配布版を信頼でき、改ざんされていないと確認できた場合に限り、ご自身で起動を承認してください。一度起動を試した後、「システム設定 → プライバシーとセキュリティ → このまま開く」を選び、表示される警告で「開く」を押します。マルウェアや破損を示す警告が出た場合は操作を止め、Appleの案内をご確認ください。

ダウンロードしたアプリを開く際のAppleの案内
Codexを表示するには

公式Codex CLI 0.160.1以降を別途インストールし、CLIの通常の手順でChatGPTにログインしてください。Codexデスクトップアプリだけでは代わりになりません。ato?がCLIをインストールしたり、新しいログインを始めたりすることはありません。

対応するCLIの場所は /opt/homebrew/bin/codex、/usr/local/bin/codex、~/.local/bin/codex です。シェルや任意のPATHは使いません。

CLIは自身の既存の認証を管理し、認証の更新やローカルのキャッシュ・状態・ログの保存を行う場合があります。ato?はログイン・ログアウト、アカウント変更、エージェント実行、ツール実行を要求しません。

— よくある質問

使う前に、
知っておきたいこと。

起動するだけで接続しますか？

同意するまでは、アプリは利用データを読まず、対応CLIも起動せず、Mac内のブリッジに空の表示データを返します。案内が表示されたら、説明を読んで「Enable AI usage」を押してください。有効化済みなら次の起動でも取得を再開し、以前オフにした設定がある場合は再同意してから再開します。ato?が新しいログインを始めることはありません。

どのMacで使えますか？

配布版は、macOS 26以降のApple Silicon Mac向けです。Intel Macには対応していません。配布版にXcodeは不要ですが、Codexの表示には公式Codex CLI 0.160.1以降とChatGPTのログインが別途必要です。Xcodeが必要なのはソースからビルドする場合です。

リングの色は、何を表していますか？

残量が20%を超えると緑、20%以下なら黄、10%以下なら赤で表示します。データを取得できない場合は「—」になります。上のプレビューはサンプルの数値で、あなたのアカウントのデータではありません。

もう一度ログインする必要はありますか？

Codexは、ChatGPTにログイン済みのCodex CLI 0.160.1以降を使います。Cursor・GrokはMac内のCursorセッション、Claudeは任意で接続するClaude Codeのステータスラインを使います。GeminiにはGoogleでログイン済みのAntigravity CLI 1.1.11以降（agy）が必要で、Gemini CLIとは別のものです。ato?がログイン操作を始めることはありません。

Claudeの残量が「—」になるのはなぜですか？

Claude Code v2.1.251以降とProまたはMaxプランが必要です。任意のステータスライン連携を設定してください。配布版は自動で接続せず、既存のカスタム設定も上書きしません。新しいAPI利用に応じて残量を更新し、画面操作による同じイベントでは古いデータの鮮度を延長しません。20分経過するかリセット時刻を過ぎると「—」になります。新しいキャッシュをすぐ読むには「Refresh」を押してください。

どのアカウントに対応していますか？

Codex、Claude Code、Cursor、Grok、Geminiの対応プランに含まれる利用枠を表示します。GeminiはAntigravity CLI経由です。APIキーの従量課金とGrokの共有型エンタープライズ利用枠には対応していません。Cursor・Grokの内部取得先は、サービス側の変更に合わせてアプリの更新が必要になることがあります。

利用データの取得を止められますか？

「Quit ato?」またはCommand-Qで、以後の定期取得とスリープ復帰時の取得を止めます。ウィンドウを閉じても取得は継続し、アプリを開き直すと再開します。進行中のリクエストが完了する場合や、macOSにウィジェットのキャッシュが残る場合があります。Claude Codeのヘルパーは独立して動くため、連携自体を止めるには別の解除手順を使ってください。

AIから残量を確認できますか？

同梱の読み取り専用CLIで、起動中のアプリの残量・リセット時刻をテキストやJSONで読めます。usage-rings-budgetスキルを別途設定すると、AIが作業の区切りに確認し、20%・10%・5%未満の残量を作業中の情報として保持します。自動で作業を止めたり、ログイン・利用データの更新・設定変更を行ったりしません。詳しくはCLIとスキルの設定手順をご覧ください。

Contextの一部ですか？

ato?は、Contextとは独立したmacOSアプリです。専用のホストアプリ、ウィジェット、ソースリポジトリがあります。

認証情報はどのように扱われますか？

Codex・Geminiは、既存の認証やキャッシュ・状態を管理する各CLIを使います。Cursor・Grokの認証情報は、対応するHTTPSの取得先にだけ使います。Claudeのヘルパーは利用枠・観測時刻と、ハッシュ化したセッション・応答の印、API利用の進行情報を保存し、古いイベントで鮮度が更新されることを防ぎます。会話や作業場所の情報は保存せず、Claude APIも呼び出しません。

利用データは誰が読めますか？

開発者側サーバーや分析サービスへの利用データの送信はありません。認証情報を含まない残量・状態・時刻・表示設定を共有します。Codex・GeminiのCLIは自身のローカル状態を保存する場合があります。Mac内のブリッジはLANに公開されませんが、同じMacの別プロセスから読めます。CLIの出力をAIへ渡すと、その利用データはAIサービスにも共有されます。

各サービスの公式ツールですか？

ato?は各サービスの公式・公認ツールではありません。Codexは公式App Serverの利用枠読み取り、Claudeは公式ステータスライン、GeminiはAntigravity CLIの利用枠出力を使います。Cursor・Grokは内部取得先のため、互換性や利用条件が変わる場合があります。各サービスの利用条件をご確認ください。
